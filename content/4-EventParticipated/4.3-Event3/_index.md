# AI From Scratch

### Event Objectives

- Review the basic ideas behind AI and Generative AI.
- See a complete example of connecting several AWS AI services.
- Understand how managed services make it easier to add AI features to an application.
- Encourage students to learn through demonstrations instead of only theory.

### Speakers

- **Nguyễn Tuấn Thịnh** - DevOps/Cloud Engineer, AWS
- **Nguyễn Công Minh** - DevOps Engineer, AWS
- AWS Vietnam specialists
- **Mai Hoàng Đỉnh** - Lecturer, IA Department, FPT University HCMC

### Key Highlights

#### Introduction to Artificial Intelligence

The session explained the difference between traditional AI and Generative AI in a simple way. I learned that the cloud can reduce the amount of infrastructure a developer has to prepare before testing an AI feature.

#### AWS AI Services

The demonstration connected Transcribe, Translate, Comprehend, Lex and Polly into a conversational flow. Amazon Bedrock was introduced for foundation models, while Knowledge Bases and vector stores showed how RAG can bring organization data into an answer.

#### Deployment and Development Practices

The speakers also discussed choosing a deployment method based on the project's size, traffic and maintenance needs. This reminded me that an AI model is only one part of a usable application; the API, storage, permissions and monitoring also matter.

#### Interactive Activities

At the end, I joined the game with a classmate. We won and received a one-month ChatGPT Plus subscription. The activity made the seminar more relaxed and gave participants a chance to interact directly.

### Key Takeaways

- AWS AI services can be arranged as separate steps in one application flow.
- Bedrock allows developers to use foundation models without managing the model infrastructure themselves.
- RAG depends on both the quality of the source data and the retrieval design.
- Demonstrations helped me understand the services faster than reading definitions alone.

### Applying to Work

For the expense system, the session encouraged me to validate AI output before saving it and to consider managed services when they fit the project. I also want to study Bedrock and RAG further after finishing the current OCR and Gemini work.

### Event Experience

I found this event easy to follow because the speakers showed how the services connect in sequence. The hands-on style made the topic less abstract, especially for a student who is still learning cloud architecture.

### Lessons Learned

AI integration should start from a clear use case and a manageable data flow. I also learned that checking input, output and failure cases is just as necessary as making the first demo work.
