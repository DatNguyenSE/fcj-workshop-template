### Mục tiêu tuần 5

* Phối hợp cùng team Backend xây dựng các thành phần cốt lõi cho hệ thống Snaptics.
* Phân tích yêu cầu và thống nhất luồng dữ liệu, cấu trúc API giữa Backend và Frontend.
* Hỗ trợ thiết kế các module, business logic và quy ước tổ chức source code Backend.
* Thiết kế database, xác định các bảng, mối quan hệ và dữ liệu cần thiết cho hệ thống.
* Hỗ trợ xây dựng và kiểm thử các API phục vụ những chức năng chính của hệ thống.
* Kiểm tra tính khớp nối giữa API Backend và giao diện Frontend.
* Phối hợp xử lý lỗi, trao đổi yêu cầu và cập nhật tiến độ giữa hai nhóm Backend và Frontend.
* Ghi chép tài liệu kỹ thuật và kết quả triển khai để team có thể tiếp tục phát triển hệ thống.

* Làm cầu nối trao đổi yêu cầu, tiến độ và các vấn đề kỹ thuật giữa hai nhóm Backend và Frontend.
* Hoàn thiện tài liệu kỹ thuật và tổng kết các phần việc cần tiếp tục phát triển.
